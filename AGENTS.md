# Clean & Shine Rheine

Static HTML rebuild of cleanandshine-rheine.de (same content structure, new design).

## Preview

```bash
python3 -m http.server 4321
```

Open http://127.0.0.1:4321

## Pages

- `index.html` – Startseite
- `dienstleistungen.html` – Dienstleistungen
- `unser-team.html` – Unser Team
- `galerie.html` – Vorher/Nachher Galerie
- `blog.html` / `blog-professionelle-gebaeudereinigung-rheine.html`
- `jobs.html` – Karriere
- `kontakt.html` – Kontakt & Angebot
- `impressum.html` / `datenschutz.html`

## Structure

- `css/styles.css` – layout and design
- `js/main.js` – mobile nav, reveals, before/after sliders
